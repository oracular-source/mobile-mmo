# Ashfen Hollow (working title)

A mobile MMO prototype inspired by EverQuest and Dreadmyst: tab-target combat, classic classes, camps and named mobs, in a dark 2D pixel-art style.

## Play
Open `index.html` in a phone or desktop browser, or play the hosted version on GitHub Pages once it's enabled (see below).

Live: https://oracular-source.github.io/mobile-mmo/ (Druid prototype: Gate Road, the Sunken Graveyard and Dungeon 1).

## Project docs
- `docs/board.md`: the work: now, next, roadmap, idea backlog, known issues, changelog
- `docs/design.md`: the game design (rules, classes, zones, dungeon)
- `docs/credits.md`: where every asset came from
- `art/palette.md`: the pixel art palette
- `CLAUDE.md`: standing instructions for Claude when working in this repo

## Hosting on GitHub Pages
Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)` → Save. After a minute or two the game is live at `https://<your-username>.github.io/<repo-name>/`.
