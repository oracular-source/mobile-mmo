- **v0.73** **Crash reports** (owner, Nov 22, after a freeze fighting the Bellringer). Before, one error inside the game loop stopped it for good: the screen froze, or went black if it broke mid-draw. Now each frame's update, drawing and HUD run inside a guard (`js/crash.js`): the error is caught, the game keeps going, and a small grey bar says **Something went wrong** with **Copy report**. The report holds the error and where in the code it happened, version, phone, class and level, area, your health, target, pet, nearby mobs (and what they were casting), skill picks, settings and the last 60 Log lines. The last 3 reports are saved (they survive a reload) and can be copied any time from **Menu → Settings → Game → Copy crash report**; on a phone it opens the share sheet so you can paste it into a chat. Never pauses the game. No save version change.

- **v0.92** **Smoother frames and no freeze at doorways** (optimization lane, item 3, first pass). Measured every area headless: game rules take under 0.1 ms a frame, so the cost is all drawing. **(1) Trees on screen:** every frame the game checked every tree in the area to see which were in view (about 3,000 in Wolfwood counting the woods past the edges, 2,700 at the crossroads) for the ~100 on screen; that check made over half of each frame's throwaway memory, which the phone has to clean up in little pauses (stutter). Trees are now sorted into 128-pixel squares once, and each frame only the squares in view are checked. Throwaway memory per frame halved (Wolfwood 89 → 43 KB, crossroads 83 → 34 KB). Also one less save/restore per sprite. **(2) Doorways:** the first visit to an area used to paint its whole map right there (Wolfwood ~0.65 s on a laptop, longer on a phone: the screen froze as you stepped through). Now the areas your exits lead to are built ahead, one at a time, in a spare moment when **nothing is fighting you**; stepping through is instant (Wolfwood 657 → 1 ms, Dungeon 1's stairs 99 → 1 ms). Area building has no random rolls, so a pre-built area is identical. **Dungeon 1 still starts fresh every run:** a floor you've walked is thrown away and rebuilt clean in the background once you're back outside.
