# Phase 2 roadmap: the solo prototype

Goal: prove the core is fun (combat, loot, a dungeon run, and classes that feel different) before building multiplayer. Each milestone ends with a check you can feel in your hands. "Sessions" are rough counts of one-feature work sessions.

| # | Milestone | What gets built | Done when | Sessions |
| --- | --- | --- | --- | --- |
| 0 | Controls and core combat | Spell pad, loadouts, auto-cast, Druid spells, Gate Road and graveyard mobs, guards | You can fight and kite comfortably on your phone | Done (v0.6) |
| 1 | Basic loot | Personal loot drops, bags, 8 gear slots, stats that matter, coin, selling to the peddler | Kills feel rewarding even between dings | 2–4, in progress |
| 2 | First dungeon | Entrance at the back of the graveyard; a 15–20 minute instanced crypt, scaled for one player; trash pulls, a named boss with its own drops, journal entries | A run is fun enough to repeat | 5–8 |
| 3 | Two more classes | A real class system (no more Druid-only code), then Warrior and Necromancer with their own spells and sprites, and a class pick at the start | Each class plays differently on the road and in the dungeon | 6–10 |
| 4 | Polish and gate review | Sound effects, a tuning pass across all three classes, a start screen, friend play-tests | A friend can play from a link without help | 4–6 |

**Moved to later:** the rest of Zone 1 (Wolfwood Edge, the Mire, Ruined Chapel), stat points, quests and the hub city. Druid tuning stops at "good enough"; all classes get balanced together once there are several to compare.

## Gate review (after milestone 4)
Share the link with 5–10 friends, collect feedback with a short form, then decide:
1. Is the core fun?
2. Stay on web (Phaser + Capacitor) or move to Godot?
3. Start phase 3 (server and multiplayer)?

## Decisions needed along the way
- [ ] Before the dungeon: setting and working title, so the dungeon and boss names are written once
- [ ] Before milestone 3: confirm Warrior and Necromancer as the next two classes
- [ ] At the gate review: web or Godot for the long run

## Not in phase 2
Multiplayer, accounts, crafting, auction house, monetization.
